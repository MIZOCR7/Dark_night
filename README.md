# The Dark Night

Welcome to **The Dark Night**, a Halloween theme game where a knight walks in the dark night, note that U will face endless skeletons coming from the sky. 

## Description

I am incredibly proud to have built this entire game from scratch! Instead of relying on heavy game engines like Unity or Godot, I used **pure Python and Pygame**, even simple physics theories I have written on my own.

## Getting Started

### Dependencies

- Python installed on your system
- Pygame library

### Installing

Linux: https://github.com/MIZOCR7/Dark_night/releases/download/v1.0.0/DarkNight-linux.tar.gz

Windows: https://github.com/MIZOCR7/Dark_night/releases/download/v1.0.0/DarkNight-windows.zip

Mac: https://github.com/MIZOCR7/Dark_night/releases/download/v1.0.0/DarkNight-mac-arm64.zip

### Executing program

You can play the game in one of two ways:

### Option 1: Quick Play (No Setup Required)
1. Download the standalone executable (`.exe`) from the https://github.com/MIZOCR7/Dark_night/releases/tag/v1.
2. Double-click the file to launch the game instantly. No Python or extra dependencies needed!

### Option 2: Run from Source Code
If you prefer to run the raw code, follow these steps in your terminal or PowerShell:

1. Clone the repository:
   ```bash
   git clone [https://github.com/MIZOCR7/Dark_night](https://github.com/MIZOCR7/Dark_night)
then pip3 if U have mac or pip if U have windows: pip install pygame, then run the game from the code directly
